## 一句话

Isla 的**账本与记忆核心**已经接进 Ametrine，但它还不是“Isla 全量融合”：archive/maintenance、digest/brief、真实向量入库、Isla 原前端和大部分旧数据还没进来；house 已有只读快照。

## 当前可用能力

### 个人账本

- `personal_ledger`：按租户一条 append-only 哈希链，原始行存 `payload`。
- 追加、列表、单条读取、链校验、JSONL 导出。
- 撤回 / 失效：必须写理由，只追加 `retract` / `expiry` trace；目标进入 `barred` / `retired`，原文仍可读。
- 操作留痕：`retract` / `expiry` / `pref` / legacy `label` 可审计。

### 记忆门

- `memory`：work / life / pref / diary / retract / expiry 的 phase、strength、holding。
- 只有明确保留的原话进入 stable；构建谈话（work）不会自动变成记忆。
- 当前 dev 数据（2026-11-24）：
  - 361 行，`ledger_ok`
  - tail `98ea5521d08518d82829c0ae4f982e205502b5ff2f97da2f602df826ab03af34`
  - `barred 293 / labile 3 / stable 0 / dormant 11 / retired 0`，holding 3
  - house 快照：250 条旧 house events、26 颗晶石、4 张卡、1 个讨论、4 个人物状态
  - 数字会随日期推进变化，不要把它当固定断言。

### 检索与结构

- 原话检索：`pg_trgm` GIN。
- 文档词法检索：`scope-search`，按可读数据库权限过滤。
- 文档向量检索通路：`vector-search`，embedding + Milvus + RRF + 回表水合；失败返回 `degraded=true`，不伪装成空结果。
- 周期：ISO week / month / quarter / year，支持详情。
- 决定线索：规则提取，标 active / expired；是档案，不等于记忆。
- 别名 / 指代：从账本抽 `叫我`、`我是老二`、`A/B/C` 群体；没依据就拒绝。
- 本体：从 speech 行现算 actor / channel / session / date / kind / term；不写第二份图文件。

### Day 与 Digest

- `GET /api/personal/day?date=YYYY-MM-DD`：05:00 → 次日 05:00，五段节律；只读账本与 house 快照。
- `GET /api/personal/digest?level=week|month|quarter|year&key=...`：区间概览、每天第一条、actors、决定线索、失效。
- `GET /api/personal/digest/span?q=上周|这个月|最近`：把口语时间范围解析成同一份 digest。
- 前端 `/personal/day`；周详情弹层内嵌 digest。

### Jobs / Bulk / Ingest

- `POST /api/personal/bulk`：一次请求最多 2000 条，单事务追加；写 `personal_job` 记录。
- `POST /api/personal/ingest`：上传 `.jsonl/.ndjson/.txt/.md`（≤5 MB），解析后走同一批量路径。
- `GET /api/personal/jobs`：查看批量/摄入任务状态；任务同步执行，没有隐藏队列。
- 拒绝账本行、机器留痕和非法 kind；批量失败整体回滚并记 failed。

### Brief / Gold / Audit

- `POST /api/personal/utterances`：写入后返回 brief 回执；个人页「写一句」直接显示。
- Gold：真实 fixture `tests/fixtures/gold-resolve.json` + `scripts/check_personal_gold.py`，当前真实账本 **10/10 gold_ok**。
- Audit：`GET /api/personal/audit`，trace 列表 + 整条账本 replay verdict；个人页显示审计状态。
- 旧 label 导入改成用目标行的 `occurred_at`，不再用 `now()`；重复导入 tail 稳定。

### Now / Replay / 维护

- `GET /api/personal/now`：最后一句原话、隔了多久、还没退休的决定；个人页「现在」。
- `GET /api/personal/replay`：真正重放账本哈希链，返回 seq/id/hash/verdict。
- `POST /api/personal/maintenance/rebuild`：重算 memory/decisions/aliases/ontology，不写库；用于诊断。
- 这三个都不依赖 LLM/embedding。

### 旧聊天与设置迁移

- `scripts/import_isla_chat.py` 导入旧 `chat_turns`：5 个会话、36 条消息（默认跳过 `s-*` 测试会话）。
- 只导入 `chat.actor`；`settings.json` 里的 provider key **不读取、不写入**。
- 现有 chat UI 可直接看到这些历史会话；chat 生成仍未接通。

### 快照

- `POST /api/personal/snapshots` 生成 zip：`ledger.jsonl` + `house.json` + `MANIFEST.json`。
- `GET /api/personal/snapshots` 列表；`GET /api/personal/snapshots/{name}` 下载。
- 文件名由租户 + 账本 tail 决定，不带墙钟；同一 tail 重建覆盖同一快照。
- 恢复是 CLI：`scripts/restore_personal_snapshot.py`，只允许恢复进**空租户**，拒绝覆盖已有账本。
- 已用真实 361 行快照恢复到临时空租户，`ledger_ok`，测试后已清理。

### House（只读）

- `personal_house` 保存一份从 `house/truth.db` 导入的只读快照。
- 提供 overview / persons / rooms / crystals / cards / discussion 详情。
- Isla 的 house 本来就没有 HTTP 写接口，所以这里不造写模型。
- 数据来自真实 `house/truth.db`，不是测试桩。

### C 端与运营

- personal 租户模式、`/personal` 页面、登录后按租户模式落地。
- 手动「写一句」：不经过模型，直接进账本。
- 设置：称呼、时区；导出完整 JSONL。
- 开户：`POST /api/personal/bootstrap`，不动注册主流程。
- 配额：个人页展示日/月用量；管理员 `/admin/personal` 直接改配额，0 = 无限制。
- 权限：账本 / 记忆 / 检索端点要求 `Tenant.mode=personal`；knowledge 租户返回 403。`settings` 与 `bootstrap` 只要求登录，前者是用户偏好，后者负责开户。

- `level`、`key`、`start`、`end`

## 关键不变量

1. **账本只增不改。** 正常业务不 `UPDATE` / `DELETE` `personal_ledger`；更正靠追加 trace。
2. **Isla 是系统身份，不是可选 assistant。** 没有 `assistant` 参数，没有 `default_assistant` 字段；不要重新引入。
3. **账本 / 记忆 / 检索端点必须校验租户模式。** 不能只看 `user.tenant_id`；`settings` / `bootstrap` 是例外。
4. **0 = 无限制。** 配额判断不要改成“0 额度”。
5. **没有模型就明确降级。** 不用假 embedding、假 Milvus、假向量；词法检索是兜底，不是向量。
6. **原文与机器留痕分开。** 账本列表默认隐藏 `label/retract/expiry/day/diary/pref`；审计走 `/traces`。
7. **不覆盖 Isla 源账本。** `/Users/young/Isla/truth/ledger.jsonl` 是源数据，导入只读。

## 已知坑

- 本地开发库依赖真实 Postgres；测试库用独立 schema，但 `Base.metadata.create_all(checkfirst=False)` 是必要的，否则会误用 public 的 `role` 表。
- 记忆计数随日期变化，`today` 不同结果不同。
- 导入后 `seq` / `id` 固定，不能手改 JSONL 或账本行。
- `POSTGRE_ADDR` 必须是 asyncpg URL；CI 里用 `postgresql+asyncpg://...`。
- 前端 `pnpm run check` 同时跑 tsc、eslint、vitest；不要只跑 vitest。
- 管理页需要真实 admin 账号才能截图验收；本地默认用户不是 admin。
- `/api/chat` 现在会因模型/ tokenizer 不可用而 503，这属于环境限制。
