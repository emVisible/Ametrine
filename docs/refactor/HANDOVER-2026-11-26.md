## 关键不变量

1. **账本只增不改。** 正常业务不 `UPDATE` / `DELETE` `personal_ledger`；更正靠追加 trace。
2. **Isla 是系统身份，不是可选 assistant。** 没有 `assistant` 参数，没有 `default_assistant` 字段；不要重新引入。
3. **账本/记忆/检索端点必须校验 `Tenant.mode=personal`。** `settings` / `bootstrap` 是例外。
4. **0 = 无限制。** 配额判断不要改成“0 额度”。
5. **没有模型就明确降级。** 不用假 embedding、假向量；词法检索是兜底。
6. **导入必须可复现。** 旧 label 使用目标行 `occurred_at`，不用 `now()`；重复导入 tail 必须稳定。
7. **机器留痕与原话分开。** 列表隐藏 `label/retract/expiry/day/diary/pref`；审计走 `/traces`、`/audit`。
8. **旧 provider key 不进新库。** 迁移只取非敏感设置。

## 已知坑

- 测试 schema 必须 `create_all(checkfirst=False)` 并自建 `role` 1/3，否则会误用 public schema 或触发外键。
- 记忆计数随日期变化；`today` 不同结果不同。
- 导入的 label 若用墙钟会导致 tail 漂移；已修复。
- `POST /api/chat` 当前 503 属于模型/ tokenizer 缺失，不是路由坏了。
- 向量 `/vector-search` 在无模型/无 Milvus 时返回 degraded，不是空结果。
- 管理页需要真实 admin 账号才能截图验收；本地默认用户不是 admin。
- CI 冷装很慢；不要用逐错 push 当调试器。

## 建议下一步
